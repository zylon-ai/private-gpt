[Straitly](https://straitly.ai) is an AI gateway with an OpenAI-compatible endpoint at `https://api.straitly.ai/v1`. One API key reaches more than 150 chat models, including Claude, GPT, Gemini, Grok and DeepSeek, so you can switch the model PrivateGPT answers with by changing a model ID. Billing is per token from prepaid credits. PrivateGPT uses it through the existing OpenAI-compatible integration.

Straitly serves chat models and does not serve embedding models. This setup sends chat requests to Straitly and keeps embeddings on your own embeddings server, for example a local [Ollama](/providers/ollama) instance.

## Capabilities with PrivateGPT

| Capability | Status |
|---|---|
| Model discovery (`/v1/models`) | ✅ includes `context_length` for each model |
| Tokenizer endpoint (`/tokenize`) | ❌ |
| Embeddings | ❌ use a separate embeddings server |
| Tool / function calling | ✅ model-dependent |
| Structured output (JSON schema) | ✅ model-dependent |
| Streaming | ✅ |
| Vision / image input | ✅ model-dependent |

Tool calling, structured output and image input depend on the model. `/v1/models` lists `supported_parameters` (for example `tools` and `response_format`) and `architecture.input_modalities` for each model, so check the model you pick there.

## Setup

<Steps>
  <Step title="Create a key and pick a chat model">
    1. Sign up at [straitly.ai](https://straitly.ai/signup), add prepaid credits, and create an API key on the [API keys page](https://straitly.ai/app/keys).
    2. Set `STRAITLY_API_KEY` in your environment or `.env` file. Keep the secret out of committed files.

    ```bash
    export STRAITLY_API_KEY="your-straitly-api-key"
    ```

    3. List the model IDs and use one of them unchanged:

    ```bash
    curl https://api.straitly.ai/v1/models \
      -H "Authorization: Bearer $STRAITLY_API_KEY"
    ```

    The same list is on the [models page](https://straitly.ai/models). The examples below use `deepseek/deepseek-v4-1-flash`; replace it with any chat model ID from the list.
  </Step>

  <Step title="Start a local embeddings server">
    Skip this step if you already have an embeddings server. Otherwise, start Ollama and pull an embeddings model:

    ```bash
    ollama pull mxbai-embed-large
    ```

    The examples below use Ollama's OpenAI-compatible API at `http://localhost:11434/v1` with the placeholder key `ollama`.
  </Step>

  <Step title="Run PrivateGPT">
    <Tabs>
      <Tab title="Package install">
        ```bash
        OPENAI_API_BASE=https://api.straitly.ai/v1 \
          OPENAI_API_KEY="$STRAITLY_API_KEY" \
          OPENAI_EMBEDDING_API_BASE=http://localhost:11434/v1 \
          OPENAI_EMBEDDING_API_KEY=ollama \
          PGPT_LLM_DEFAULT=deepseek/deepseek-v4-1-flash \
          PGPT_EMBEDDING_DEFAULT=mxbai-embed-large \
          private-gpt serve
        ```
      </Tab>
      <Tab title="Docker">
        ```bash
        docker run -p 8080:8080 \
          -e OPENAI_API_BASE=https://api.straitly.ai/v1 \
          -e OPENAI_API_KEY="$STRAITLY_API_KEY" \
          -e OPENAI_EMBEDDING_API_BASE=http://host.docker.internal:11434/v1 \
          -e OPENAI_EMBEDDING_API_KEY=ollama \
          -e PGPT_LLM_DEFAULT=deepseek/deepseek-v4-1-flash \
          -e PGPT_EMBEDDING_DEFAULT=mxbai-embed-large \
          zylonai/private-gpt:latest
        ```

        `host.docker.internal` is provided by Docker Desktop. On Linux Docker Engine, add `--add-host=host.docker.internal:host-gateway`.
      </Tab>
      <Tab title="uv (local)">
        ```bash
        OPENAI_API_BASE=https://api.straitly.ai/v1 \
          OPENAI_API_KEY="$STRAITLY_API_KEY" \
          OPENAI_EMBEDDING_API_BASE=http://localhost:11434/v1 \
          OPENAI_EMBEDDING_API_KEY=ollama \
          PGPT_LLM_DEFAULT=deepseek/deepseek-v4-1-flash \
          PGPT_EMBEDDING_DEFAULT=mxbai-embed-large \
          uv run private-gpt serve
        ```
      </Tab>
    </Tabs>

    Follow the corresponding [installation guide](/installation/package) first, including PrivateGPT's other required services.
  </Step>
</Steps>

## Advanced profile example

There is no `/tokenize` endpoint, so set `context_window` explicitly. Copy it from the model's `context_length` in `/v1/models`.

```yaml
# settings-model.yaml
llm:
  default_model: deepseek/deepseek-v4-1-flash

models:
  - name: deepseek/deepseek-v4-1-flash
    type: llm
    mode: openai
    context_window: 1048576
    support_tools: true
    support_reasoning: true
```

Run with the profile:

```bash
OPENAI_API_BASE=https://api.straitly.ai/v1 \
  OPENAI_API_KEY="$STRAITLY_API_KEY" \
  OPENAI_EMBEDDING_API_BASE=http://localhost:11434/v1 \
  OPENAI_EMBEDDING_API_KEY=ollama \
  PGPT_EMBEDDING_DEFAULT=mxbai-embed-large \
  PGPT_PROFILES=model \
  uv run private-gpt serve
```

## Notes

- **Model IDs** usually carry the lab prefix, for example `deepseek/deepseek-v4-1-flash`. Use them exactly as `/v1/models` returns them.
- **Embeddings stay on your server**, but retrieved document excerpts that PrivateGPT puts into a chat prompt are sent to the hosted API.
- Straitly also accepts the Anthropic Messages API. PrivateGPT uses the OpenAI-compatible endpoint, and Claude models are available on it too.
