---
title: "Atlas Cloud"
description: "Configure PrivateGPT with Atlas Cloud for OpenAI-compatible chat models and a separate local embeddings server."
---

[Atlas Cloud](https://www.atlascloud.ai) is a hosted, OpenAI-compatible gateway for open and proprietary models at `https://api.atlascloud.ai/v1`. PrivateGPT can use it through the existing OpenAI-compatible integration.

Atlas Cloud serves chat models and does not provide an embeddings endpoint. This setup sends chat requests to Atlas Cloud and keeps embeddings on your existing embedding setup, for example a local [Ollama](/providers/ollama) server. It does not require a new PrivateGPT backend.

## Setup

<Steps>
  <Step title="Create a key and choose a chat model">
    1. Sign up at [atlascloud.ai](https://www.atlascloud.ai) and create an API key in the [console](https://console.atlascloud.ai/api-keys).
    2. Set `ATLASCLOUD_API_KEY` in your environment or `.env` file. Keep the secret out of committed files.

    ```bash
    export ATLASCLOUD_API_KEY="your-atlascloud-api-key"
    ```

    3. List the public model catalog and pick the exact ID of a chat model from the response:

    ```bash
    curl https://api.atlascloud.ai/v1/models
    ```

    ```bash
    export ATLASCLOUD_MODEL="deepseek-ai/deepseek-v4-flash"
    ```

    Model IDs include the lab prefix, for example `deepseek-ai/deepseek-v4-flash`. The catalog changes over time, so check it before pinning an ID. See the [Atlas Cloud docs](https://www.atlascloud.ai/docs) for the API reference.
  </Step>

  <Step title="Start a local embeddings server">
    Skip this step if you already have an embeddings server. Otherwise, start Ollama and pull the embeddings model:

    ```bash
    ollama pull mxbai-embed-large
    ```

    These examples use Ollama's OpenAI-compatible API at `http://localhost:11434/v1`, with the separate placeholder key `ollama`.
  </Step>

  <Step title="Run PrivateGPT">
    <Tabs>
      <Tab title="Package install">
        ```bash
        OPENAI_API_BASE=https://api.atlascloud.ai/v1 \
          OPENAI_API_KEY="$ATLASCLOUD_API_KEY" \
          OPENAI_EMBEDDING_API_BASE=http://localhost:11434/v1 \
          OPENAI_EMBEDDING_API_KEY=ollama \
          PGPT_LLM_DEFAULT="$ATLASCLOUD_MODEL" \
          PGPT_EMBEDDING_DEFAULT=mxbai-embed-large \
          private-gpt serve
        ```
      </Tab>
      <Tab title="Docker">
        ```bash
        docker run -p 8080:8080 \
          -e OPENAI_API_BASE=https://api.atlascloud.ai/v1 \
          -e OPENAI_API_KEY="$ATLASCLOUD_API_KEY" \
          -e OPENAI_EMBEDDING_API_BASE=http://host.docker.internal:11434/v1 \
          -e OPENAI_EMBEDDING_API_KEY=ollama \
          -e PGPT_LLM_DEFAULT="$ATLASCLOUD_MODEL" \
          -e PGPT_EMBEDDING_DEFAULT=mxbai-embed-large \
          zylonai/private-gpt:latest
        ```

        `host.docker.internal` is provided by Docker Desktop. On Linux Docker Engine, add `--add-host=host.docker.internal:host-gateway`. Ollama must listen on an address reachable from the container.
      </Tab>
      <Tab title="uv (local)">
        ```bash
        OPENAI_API_BASE=https://api.atlascloud.ai/v1 \
          OPENAI_API_KEY="$ATLASCLOUD_API_KEY" \
          OPENAI_EMBEDDING_API_BASE=http://localhost:11434/v1 \
          OPENAI_EMBEDDING_API_KEY=ollama \
          PGPT_LLM_DEFAULT="$ATLASCLOUD_MODEL" \
          PGPT_EMBEDDING_DEFAULT=mxbai-embed-large \
          uv run private-gpt serve
        ```
      </Tab>
    </Tabs>

    Follow the corresponding [installation guide](/installation/package) first, including PrivateGPT's other required services.
  </Step>
</Steps>

## Model limits and capabilities

- Use the model ID returned by `/v1/models` unchanged, including the lab prefix.
- `/v1/models` returns `context_length` for each model, so PrivateGPT can set the context window from discovery.
- Tools, structured outputs, reasoning, and image input depend on the selected model. Check `supported_features` and `input_modalities` in the `/v1/models` response.
- Not every catalog entry is a chat model (for example, it includes image models such as `openai/gpt-image-2`). Choose a chat model for `PGPT_LLM_DEFAULT`.
- Model discovery has a short timeout. If the catalog request is slow and PrivateGPT cannot find the default model at startup, start it again.
- The examples keep embeddings on a separate server. Retrieved document excerpts included in a chat prompt are still sent to the hosted API.
